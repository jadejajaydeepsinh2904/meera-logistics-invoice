TRANSPORTBAHI V7.0 - GITHUB WEB UPDATE ONLY
============================================

આ ZIPમાં ફક્ત Web માટેની 25 બદલાયેલી જરૂરી files છે.
Android project, node_modules, tests અને જૂના reports તેમાં નથી.

GitHubમાં Upload કરવાની રીત:

1. આ ZIPને Extract કરો.
2. તમારા હાલના Website GitHub Repositoryને ખોલો.
3. Add file > Upload files પસંદ કરો.
4. Extract થયેલા folderની અંદરની package.json, package-lock.json અને public folder પસંદ કરો.
5. નીચે Commit changes દબાવો.
6. Vercel આપમેળે નવી Web version deploy કરશે.

ખાસ ધ્યાન:

- ZIPનો બહારનો TransportBahi folder GitHubમાં upload કરશો નહીં.
- તેની અંદરની files/folders Repositoryના rootમાં upload કરવાના છે.
- જૂનું android folder delete કે upload કરવાની જરૂર નથી.
- Meera Logisticsના invoice/company dataમાં કોઈ ફેરફાર થતો નથી.
