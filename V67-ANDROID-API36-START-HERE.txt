ANDROID STUDIO BUILD
1. Install/update Android Studio Otter 2025.2.1 or newer.
2. Use JDK 21 and Android SDK 36.
3. Open the repository folder in Terminal.
4. Run: npm install
5. Run: npm run android:sync
6. Run: npm run android:open
7. In Android Studio, wait for Gradle Sync and run on a real Android phone.
