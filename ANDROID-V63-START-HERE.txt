TRANSPORT ERP — V63 ANDROID APP FOUNDATION

WHAT V63 DOES
- Keeps the full web ERP and V62 backend.
- Adds Capacitor Android application configuration.
- App ID: in.meeralogistics.transporterp
- App Name: Transport ERP
- Uses public/ as the Android web bundle.
- Existing Cloudflare Worker remains the backend.
- Login/session/data stay server-side as before.
- Android hardware Back button closes popup/modal first, returns to Dashboard next, exits only from Dashboard.
- External web links/WhatsApp can open outside the app.
- Invoice text sharing uses the Android native share sheet when available.
- Existing camera/gallery file input and V62 multipart document upload are retained.
- V62 private document Blob/PDF viewing is retained.
- Offline/PWA service worker remains available for the normal web version.

FIRST ANDROID BUILD
1. Install Android Studio (current stable) and Node.js.
2. Extract the FULL V63 project.
3. Terminal in project:
   npm install
   npm run android:preflight
   npm run android:add
   npm run android:sync
   npm run android:open
4. In Android Studio wait for Gradle sync.
5. Test on a real Android phone.
6. For testing APK: Build > Build APK(s).
7. For Play Store later: Build > Generate Signed App Bundle / APK > Android App Bundle.

IMPORTANT
- V63 is the Android foundation/source project, not a pre-signed Play Store AAB.
- Do not publish before Google Play Billing, privacy/data safety and account-deletion flow are finalized.
- Do not change the package ID after Play Store production launch.
